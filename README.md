# Neil Aldrin T. Olvina — Professional Portfolio

A responsive static portfolio website built from the provided CV and EdTech Impact Report.

## Files

- `index.html` — site structure and content
- `styles.css` — responsive visual system
- `script.js` — project filtering, case-study modal, mobile navigation, scroll effects
- `assets/` — place additional assets here

## Adding the CV

The website expects the provided resume at:

`assets/OLVINA - UPDATED RESUME (5).pdf`

If you move or rename the CV, update the links in `index.html`.

## Local preview

Because this is a static site, you can open `index.html` directly in a browser. For best results, serve the folder through a local HTTP server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

`http://localhost:8000`

## Deployment

This can be deployed directly to:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- Any standard static web host

No build step is required.

## Content integrity

The site intentionally uses only information supported by the supplied CV and EdTech Impact Report. It does not invent testimonials, awards, partnerships, publications, or statistics.
